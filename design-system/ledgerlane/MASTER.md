# Ledgerlane — Midnight Ledger System

## Intent

Finance software that feels calm under pressure: editorial hierarchy, controlled contrast, and evidence-led interfaces. The visual language is **Midnight Ledger** — ink surfaces, cobalt illumination, and a precise mineral accent.

## Tokens

- Canvas: `#07111F`; elevated surface: `#0D1B2D`; panel: `#11253D`
- Ink: `#F5F8FC`; muted: `#AAB8CA`; subtle: `#71839B`
- Primary: `#6F8CFF`; accent: `#8DE1C1`; warning: `#FFB86B`
- Radius: 12 / 18 / 28px; spacing uses 4px and 8px increments.
- Headings: `ui-serif, Georgia, serif`; body: system sans-serif.

## Rules

- Use one dominant action per viewport and preserve 44px minimum touch targets.
- Body text is at least 16px on mobile. Keep long-form copy within 65 characters.
- Use SVG-like geometric marks and text labels, not emoji as structural icons.
- Motion is opacity/transform only, 180–280ms, and disabled under reduced motion.
- Use `#8DE1C1` with text/icon labels for positive state; never color alone.
